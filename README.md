# Kuria — AI, made visible.

A lightweight, responsive portfolio for Kuria’s AI creator work. Built with plain HTML, CSS, and JavaScript so it can be hosted on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static web host.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder.

## Before publishing

- Replace or expand the three featured work links with direct posts, videos, or case studies.
- The supplied portrait and AI & Tech collaboration banner in `assets/` are already used on the page; replace them if you have higher-resolution originals.
- Push the folder to a GitHub repository and connect that repository to your preferred static host.
